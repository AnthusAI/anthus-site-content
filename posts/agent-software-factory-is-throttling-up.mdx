The agent software factory is throttling up.

Last Friday through this one: five new Anthus projects.

Chatticus: a shared space where people and bots work on the same files and approvals, more office than chat window.

Spotticus: a background task queue for ensuring that your AI account quotas don't go to waste when you're not using them.

Pudicus: an 'inspected by' sticker system for quality assurance bots to tag commits.

Markus: Anthus-Flavored Markdown that includes support for fancy stuff like heroes and columns and pull quotes and expanding sections.

Antharchy: our Arch desktop for bots and people, an Anthus fork of Omarchy.

We are orbiting the singularity.
