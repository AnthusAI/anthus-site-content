## What it is

Chatticus is Anthus's answer to multi-user agent groupware. People and named bots share one room: common files, tools, memory, and a system of authority and approvals. It's like an office, not a chat window.

## What it does

- Gives each bot a durable name, memory, and role so context compounds across turns.
- Runs work on one shared computer owned by the user, not a siloed machine per bot.
- Treats skills, routines, and approval boundaries as first-class controls.
- Keeps consequential actions (send, publish, buy, delete, permission changes) paused until a person approves.

## Why it matters

Most agent products optimize for a smarter single assistant. Chatticus optimizes for the organization: several minds in one room, with a human still in charge. That is the layer you need when bots stop being demos and start being coworkers.

## How it fits the Anthus Platform

Chatticus is the collaboration surface for the broader platform. Named teammates can drive [Tactus](/platform/tactus) procedures, track work in [Kanbus](/platform/kanbus), and host operator interfaces that sit beside [Korporus](/platform/korporus). [Antharchy](/platform/antharchy) is one of the workplaces those teammates can run.

A common pattern is [Chatticus](/platform/chatticus) + [Kanbus](/platform/kanbus) + [Tactus](/platform/tactus): share the room, remember the work, run the durable procedure.
